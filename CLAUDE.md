# Rules for Claude

## Higgsfield generation (examples/higgsfield)
Every generation costs money. Before running `npm run gen ... --yes` (or `npm start`), ALWAYS ask Pedro which model to use and tell him the estimated credit cost, then wait for his explicit approval in that conversation. Run the dry run (no `--yes`) first to show model, parameters and estimate. If the cost is unknown, say so; never guess it. Never read, print or commit `HF_CREDENTIALS`.
